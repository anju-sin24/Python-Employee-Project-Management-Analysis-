Employee-Project-Management-Analysis-

Project Overview-

This project analyzes employee and project management data to evaluate
project delivery performance, employee seniority, costs, and bonus
allocations.

The analysis covers 14 projects, 5 employee profiles, and multiple
seniority levels.

Business Problem- 

The objective was to understand:

- Project completion performance
- Employee seniority levels
- Project costs
- Employee bonus allocations
- Project delivery outcomes

Tools & Technologies-

- Python
- Pandas
- NumPy
- Jupyter Notebook

Data Preparation-

The analysis included:

- Handling missing values
- Cleaning employee records
- Applying business rules
- Updating employee seniority levels
- Combining multiple data sources
- Validating project records

Analysis-

The analysis examined:

- Project completion
- Project performance
- Employee seniority
- Bonus allocation
- Project costs

Key Results-

- Identified an 8-project completion rate.
- Analyzed employee performance across different seniority levels.
- Identified peak individual bonus allocation of ₹50,100.
